WPA2 MIC — WebGPU

MIC = первые 16 байт HMAC-SHA1(KCK, EAPOL). KCK — первые 16 байт PTK. Подходит для WPA2 descriptor version 1 (обычный WPA2-PSK).

Передайте весь EAPOL frame как hex. Для проверки MIC поле в кадре должно быть обнулено. При необходимости включите обнуление 16 байт по смещению 81 от начала EAPOL.

Тестовый вектор синтетический, рассчитан через Python hmac. Проверка не меняет введённые значения.
