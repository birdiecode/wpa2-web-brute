wpa2-web-brute

Тест полной цепочки PMK → PTK → MIC. Страница работает локально через file:/// без сервера.

Для замера один пароль повторяется во всём батче; проверяется MIC каждого результата. min(AP, STA) || max(AP, STA) || min(ANonce, SNonce) || max(ANonce, SNonce), лексикографический порядок байтов. В реальном EAPOL поле MIC должно быть обнулено заранее. По умолчанию используется синтетический тестовый вектор.
