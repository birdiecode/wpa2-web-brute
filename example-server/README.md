# Сервер примера

Node.js 20+. Библиотека `rank-lib-js` устанавливается из GitHub по SSH
с фиксацией коммита в `package.json` и `package-lock.json`.
Для установки нужен SSH-доступ к `git@github.com:birdiecode/rank-lib-js.git`.
Соседняя локальная папка `rank-lib-js` не используется.

Из корня `wpa2-web-brute`:

```bash
npm ci                  # установка и сборка WPA2-библиотеки
npm run build:server    # сборка библиотеки и установка зависимостей сервера
npm start
```

- Обработчик: <http://127.0.0.1:3000/>
- Админ-панель: <http://127.0.0.1:3000/admin>
- `GET /api/job` — резервирование задания.
- `POST /api/job` — приём хэшей интервалов и найденных паролей, выдача следующего задания.
- `GET /api/work` — прогресс и найденные пароли.
- `POST /api/reset` — сброс прогресса и резервов.

При первом запуске `job.json` создаётся из `job.example.json`. Параметры
задания и состояние интервалов хранятся в `job.json`, последний результат —
в `result.json`. Эти рабочие файлы исключены из Git. Перенесённое существующее
состояние сохраняется. Для сброса используйте кнопку в админ-панели.

Сервер отдаёт сборку WPA2 из `../dist`, а браузерную сборку RankLib —
из установленного пакета в `node_modules`. HTML-страница подключает один
`experiment.js`, который загружает библиотеки и запускает обработку.

Переменные окружения:

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `HOST` | `127.0.0.1` | Адрес сервера |
| `PORT` | `3000` | Порт |
| `JOB_TIMEOUT_MS` | `60000` | Время резервирования интервалов |
| `JOB_FILE` | `example-server/job.json` | Путь к существующему файлу задания |
| `RESULT_FILE` | `example-server/result.json` | Путь к результату |

Относительные пути в `JOB_FILE` и `RESULT_FILE` считаются от текущего каталога.
Без этих переменных сервер использует файлы рядом с `server.mjs` независимо
от каталога запуска.

Проверки планировщика: `npm test` из `example-server`.
